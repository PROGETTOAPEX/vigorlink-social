# vigorlink-social

Grafiche pubbliche dei post social di VigorLink (@vigorlink.it), già destinate alla pubblicazione.
Metricool le legge da qui tramite URL pubblico al momento della programmazione.

Struttura: `AAAA-MM-GG_CODICE/ig_01.png …` (una cartella per post).
Nessun dato personale o interno va in questo archivio: è pubblico.
